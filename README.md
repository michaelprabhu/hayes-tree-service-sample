# Hayes Tree Service — unofficial sample preview

An independent website-design demonstration by J M Enterprise using public business information. This is **not the official website of Hayes Tree Service** and is not endorsed by the business.

The photographs are free stock imagery, not examples of this business's work. The page identifies their California and Pennsylvania locations, links the original photographers and Unsplash sources, and includes the license link.

This is a static HTML/CSS/JavaScript sample with no forms, backend, analytics, tracking or booking functionality. Content and native navigation remain usable without JavaScript.

Crawler safeguards include `noindex,nofollow,noarchive` metadata, this project's `robots.txt`, and the host's existing root-level `Disallow: /` rule. These are crawler instructions, not access controls.

Business-source links, the dated rating snapshot and photo credits appear on the sample itself. Confirm any service scope, availability or pricing directly with the business.
